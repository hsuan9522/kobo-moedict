# 字典顯示範例

開啟 [index.html](index.html)，可切換純繁體注音、繁簡注音、繁簡拼音。
此檔納入版本控制，`output/` 則是忽略的可重建產物。

範例改為 32 字，依五類規則分組；每個字上方都列出檢查用途，詳細清單為
[cases.json](cases.json)。移除了用途重疊的舊字例，保留「丢、争、挀」等實機
回歸案例，並新增「攵」檢查同時向「攴、文」借音時的來源字頭與編號。

| 分類             | 檢查內容                                          |
| ---------------- | ------------------------------------------------- |
| 基本排版         | 單音、多音、輕聲、長釋義、例句與引文              |
| 繁簡對應         | 單一對應、一簡多繁、自身實義優先、完整讀音        |
| 異體字與借音     | 補音、來源編號、多正字借音、末尾分組與單層展開    |
| 引用規則         | def/link 優先、同字轉介、參見篩音、兒化、缺失目標 |
| 讀音編號運用 | 又音原文、空釋義、無詞性、地區讀音與缺字          |

較少見的「㕘、徸、鸊」仍有獨立的規則用途，因此保留；是否能顯示取決於實機字型。
多字詞只會出現在展開內容，不會成為查詢字頭。

## 重建

```sh
node scripts/preview.js
```

預覽使用正式建置的同一渲染器。若格式化輸出的 HTML，可使用 VS Code 的
Prettier；專案設定為 4 格縮排。瀏覽器的換行、字型和間距不等同 Kobo 實機。
